# ✊ Rock Paper Scissors

## 📖 Description
> Simple web game where you play Rock Paper Scissors against the computer.
The first to reach 10 points wins the game.
Made for learning basic JavaScript, DOM manipulation, and CSS styling.

---

## 🚀 Features
- [x] Play Rock Paper Scissors against the computer
- [x] Score system (first to 10 points wins)
- [x] Visual feedback for each round and game over
- [x] Responsive and clean design

---

## 🛠️ Technologies Used
- **Front-end**: HTML, CSS, JavaScript
- **Back-end** : JavaScript

---

## 📂 Project Structure

```bash
Rock_Paper_Scissors/
│── index.html      # Main HTML file
│── style.css       # Styles for the game
│── app.js          # Game logic in JavaScript
│── README.md       # Project documentation
```

## ⚙️ Installation & Usage

### 1. Clone the project

```bash
git clone https://github.com/MarineG404/Rock_Paper_Scissors.git
cd Rock_Paper_Scissors
```

### 2. Open the game

Just open `index.html` in your web browser.
No installation or dependencies needed.
